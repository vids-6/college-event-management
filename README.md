# CollegeScene — College Event Discovery

A responsive frontend website for exploring college events, including workshops, hackathons, tech talks, and cultural activities.

## Features

- Browse college events from a landing page and dedicated listings page.
- View a sample event detail page.
- Navigate using a responsive mobile menu.
- Explore event categories through interactive tabs.

## Tech Stack

HTML5, CSS3, and vanilla JavaScript. Google Fonts and externally hosted imagery are used for presentation.

## Run Locally

1. Download or clone this repository.
2. Open `index.html` in a web browser.
3. Use `events.html` to browse event listings and `event-pop-up.html` for a sample event detail page.

No installation or backend server is required.

## Project Scope

This repository contains a frontend prototype. Event listings and detail links are sample content; it does not include a working registration database, admin dashboard, or backend service.
